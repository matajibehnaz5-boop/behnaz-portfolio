سامانه دانشجویی

Student Portal

~samane-daneshjooei

سامانه دانشجویی یه داشبورد ساده‌ست که با Firebase ساختمش تا اطلاعات و فعالیت‌های دانشجویی رو یه‌جا مدیریت کنه. انگیزه‌ی اصلی این پروژه این بود که با یه دیتابیس real-time و بدون نیاز به راه‌اندازی سرور جداگانه کار کنم و ببینم چطور می‌شه یه اپلیکیشن رو سریع از صفر بالا آورد.

تو این پروژه از Firebase هم برای ذخیره‌ی داده و هم احتمالاً برای احراز هویت استفاده شده، و رابط کاربریش با جاوااسکریپت ساده پیاده‌سازی شده، بدون فریم‌ورک اضافه. تمرکز بیشتر روی این بود که ساختار داده‌ها درست طراحی بشه تا بشه بعداً امکانات بیشتری روش اضافه کرد.

این پروژه هنوز در حال توسعه‌ست؛ بخش‌های بعدی مثل نمایش نمرات و برنامه‌ی هفتگی دانشجو قراره به‌زودی اضافه بشن. لینک مخزن (repository) به‌زودی این‌جا قرار می‌گیره.

The Student Portal is a simple dashboard built with Firebase to manage student data and activity in one place. The main motivation behind this project was to work with a real-time database without setting up a separate server, and to see how quickly an application can be built from scratch.

Firebase is used both for data storage and, likely, authentication, while the interface is built with plain JavaScript, without an additional framework. The focus was mostly on designing the data structure properly so more features could be added later.

The project is still in progress; upcoming features include a grades view and a weekly student schedule. The repository link will be added here soon.
