Viyan Boutique

~viyan-boutique

بوتیک ویان یه فروشگاه آنلاین لباسه که فرانت‌اندش رو با React و Vite ساختم و بک‌اندش با Django کار می‌کنه. هدف اصلی این پروژه این بود که یه اپلیکیشن کامل با جداسازی درست فرانت‌اند و بک‌اند بسازم، به‌جای اینکه همه‌چیز رو تو یه قالب ساده‌ی HTML بریزم.

سمت بک‌اند، از Django برای مدیریت محصولات، دسته‌بندی‌ها و API استفاده شده. یکی از بخش‌های جالب پروژه، صفحه‌ی نمایش کمپینه که برای معرفی مجموعه‌های ویژه طراحی شده و جدا از صفحات معمولی فروشگاه کار می‌کنه. تمرکز زیادی روی طراحی رابط کاربری تمیز و تجربه‌ی خرید ساده گذاشتم.

این پروژه هنوز در حال توسعه‌ست و قراره امکاناتی مثل سبد خرید و پنل مدیریت کامل‌تر بهش اضافه بشه. لینک مخزن (repository) به‌زودی این‌جا قرار می‌گیره.

Viyan Boutique is an online clothing storefront with a React + Vite frontend and a Django backend. The main goal of this project was to build a full application with a proper separation between frontend and backend, rather than putting everything in a single static page.

On the backend, Django handles products, categories, and the API. One of the more interesting parts is a dedicated campaign showcase page built to highlight featured collections separately from the regular store pages. I put a lot of focus on clean UI design and a simple shopping experience.

The project is still under active development — a shopping cart and a fuller admin panel are planned next. The repository link will be added here soon.
