# وب‌سایت شخصی — بهناز متاجی

سایت شخصی دو زبانه (فارسی/انگلیسی)، ساخته‌شده با HTML/CSS/JS ساده — بدون نیاز به بیلد یا فریم‌ورک، مناسب برای انتشار روی GitHub Pages.

## ساختار پروژه
```
index.html      صفحه اصلی (مشخصات و پروژه‌ها)
style.css       استایل‌ها
script.js       سوییچ زبان فارسی/انگلیسی
assets/         تصاویر (پروفایل و اسکرین‌شات پروژه‌ها)
```

## چطور روی GitHub Pages منتشر کنم؟
1. یک ریپازیتوری جدید بسازید (مثلاً `behnaz-motaji.github.io` یا هر اسم دیگه).
2. تمام فایل‌های این پوشه رو داخل ریپو آپلود/کامیت کنید.
3. برید به **Settings → Pages**.
4. تو بخش **Branch**، شاخه‌ی `main` و پوشه‌ی `/ (root)` رو انتخاب کنید و **Save** بزنید.
5. بعد از چند دقیقه، سایت روی آدرسی شبیه این در دسترس می‌شه:
   `https://<username>.github.io/<repo-name>/`

## چیزهایی که باید بعداً تکمیل کنید
- لینک واقعی مخزن‌های `Viyan Boutique` و `سامانه دانشجویی` رو جای `href="#"` تو فایل `index.html` بذارید.
- صفحات بعدی (جزوات، درباره‌ی من کامل‌تر، منابع) رو می‌شه به همین ساختار اضافه کرد — هروقت محتوا/اسکرین‌شات‌ها آماده شد بفرستید تا اضافه کنم.
